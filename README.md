# NextJs-MongoDBClient
NextJs MongoDBClient Page Router Project
Uses Vercel to deploy the nextjs project

Add gitignore file to ignore node modules and .next folder
git add . 
git commit -m "NextJs Project"
git remote add origin "add github repo url"
git push --all


Login into Vercel using github. 
Link repositories and select repo to import and deploy. 
https://next-js-mongo-db-client-x597.vercel.app/
![image](https://github.com/user-attachments/assets/1e3c6b07-e94a-4cb6-8f47-252f6dad1535)


Any new changes commited and pushed to the branch will be automatically reflected in vercel.
Make sure in MongoDB Network Access is allowed to access from anywhere
